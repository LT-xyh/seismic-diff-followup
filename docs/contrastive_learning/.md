

### 第一阶段：物理真值制备与离线处理 (Offline Preparation)
**目标：构建绝对的物理监督信号，降低训练时的计算开销。**

1. **目标速度小波分解：** 在将数据送入网络前，提前对训练集中的目标深度速度模型（$V_{depth}$）进行二维离散小波变换（DWT）。
2. **提取物理锚点（Anchors）：**
   * 保存高频细节系数图作为 **结构锚点 ($Anchor_{struct}$)**。
   * 保存低频近似系数图作为 **数值锚点 ($Anchor_{num}$)**。
3. **数据预处理：** 将层位数据（Horizon）转换为符号距离场（SDF）；对 PSTM、RMS 速度和测井数据进行标准化对齐，确保空间网格分辨率一致（例如 $70 \times 70$）。

---

### 第二阶段：特征提取与解耦网络搭建 (Feature Extraction & Decoupling)
**目标：搭建能够提取基础特征并将其分流至独立子空间的编码器架构。**

1. **基础骨干网络（Backbones）：**
   * 输入：PSTM, Horizon(SDF), RMS, Well。  （已完成 src\models\conditional_encoder）
   * 输出：保留完整空间分辨率的基础特征 $F_{pstm}, F_{horizon}, F_{rms}, F_{well}$。
2. **三元空间投影头（Projection Heads）：**
   * 为每个基础特征配置三个并行的 **$1 \times 1$ 卷积层**（绝不能用全局池化，必须保留空间维度）。
   * 将 $F$ 投影为：
     * **结构特征 ($S$):** $S_{pstm}, S_{horizon}, S_{rms}$
     * **数值特征 ($N$):** $N_{rms}, N_{well}, N_{pstm}$
     * **特异特征 ($U$):** $U_{pstm}, U_{horizon}, U_{rms}, U_{well}$

---

### 第三阶段：核心对比学习预训练 (Contrastive Pre-training)
**目标：引入 Symile 损失与 QUEST 约束，完成特征子空间的纯化。此时完全不引入 Diffusion。**

1. **构建结构子空间 Symile 联合对比：**
   * 输入集合：$X_{struct} = \{S_{pstm}, S_{horizon}, S_{rms}, Anchor_{struct}\}$
   * 计算 Symile Loss（多对一联合重构），强迫 PSTM的纹理、层位线、RMS的隐式阶跃 **联合逼近** 高频结构真值。

2. **构建数值子空间 Symile 联合对比：**
   * 输入集合：$X_{num} = \{N_{rms}, N_{well}, N_{pstm}, Anchor_{num}\}$
   * 计算 Symile Loss，强迫 RMS的平滑背景、测井的绝对稀疏值、PSTM的隐式运动学 **联合逼近** 低频背景真值。
3. **施加特异性正交惩罚 (QUEST Orthogonality)：**
   * 对于每一个模态，计算其 $U$ 特征与 $S$、$N$ 特征的余弦相似度并最小化至 0，防止独有特征丢失。
4. **执行预训练：** 单独使用上述损失函数之和（$\mathcal{L}_{symile\_S} + \mathcal{L}_{symile\_N} + \mathcal{L}_{ortho}$）训练所有的 Encoder 和 投影头，直到损失收敛。

#### 当前代码中的增强版 Stage-3 训练目标

当前 `src/models/contrastive_learning/contrastive_pretraining_loss.py` 已经按增强路线实现为：

1. **Official MIP-shuffle Symile 作为主对比项**
   * 默认配置：
   ```yaml
   contrastive_learning:
     loss:
       symile_mode: 'official_mip_shuffle'
   ```
   * 当 `include_all_modalities_in_symile: true` 时，结构空间与数值空间默认都使用四个模态加物理锚点：
   $$
   X_{struct} = \{S_{pstm}, S_{horizon}, S_{rms}, S_{well}, Anchor_{struct}\}
   $$
   $$
   X_{num} = \{N_{pstm}, N_{horizon}, N_{rms}, N_{well}, Anchor_{num}\}
   $$

2. **Anchor Alignment（显式锚点对齐）**
   * 在 Symile 之外，额外对每个 $S_m$ 与 $Anchor_{struct}$、每个 $N_m$ 与 $Anchor_{num}$ 做直接对齐。
   * 代码中使用 `GAP -> projector -> InfoNCE` 的方式单独强化锚点吸引。

3. **S-N Orthogonality**
   * 对每个模态显式施加：
   $$
   \mathcal{L}_{SN} = \frac{1}{M} \sum_m \left| \text{sim}(S_m, N_m) \right|
   $$
   * 其目的不是保留特异性，而是直接防止“结构头和数值头学成一回事”。

4. **QUEST U Orthogonality**
   * 保留原有 QUEST 约束：
   $$
   \mathcal{L}_{QUEST} = \frac{1}{M} \sum_m
   \left(
   \lambda_S |\text{sim}(U_m, S_m)| +
   \lambda_N |\text{sim}(U_m, N_m)|
   \right)
   $$

5. **Modality Adversarial Loss for S/N**
   * 仅对 $S$ 和 $N$ 空间施加模态对抗，不作用于 $U$。
   * 代码中采用 `Gradient Reversal Layer (GRL)` + 模态分类器：
   $$
   \mathcal{L}_{adv}^{S} = \text{CE}(D_S(\text{GRL}(\text{GAP}(S_m))), y_m)
   $$
   $$
   \mathcal{L}_{adv}^{N} = \text{CE}(D_N(\text{GRL}(\text{GAP}(N_m))), y_m)
   $$
   其中 $y_m$ 是模态标签（PSTM / Horizon / RMS / Well）。该项的目标是让编码器难以从 $S/N$ 特征中保留“模态身份”。

6. **当前总损失函数**
   $$
   \mathcal{L}_{Total}
   =
   \alpha \mathcal{L}_{symile\_S}
   + \beta \mathcal{L}_{symile\_N}
   + \gamma \mathcal{L}_{QUEST}
   + \lambda_{A} \mathcal{L}_{anchor}
   + \lambda_{SN} \mathcal{L}_{SN}
   + \lambda_{adv} \mathcal{L}_{adv}
   $$
   其中：
   * $\mathcal{L}_{anchor}$ 为结构/数值两套 anchor alignment 的均值；
   * $\mathcal{L}_{adv}$ 为结构/数值两套 modality adversarial loss 的均值。

这一阶段是整个架构的**数学核心与物理灵魂**。为了让这部分不仅能完美指导代码编写，还能直接作为您未来论文中 Method 章节的核心公式（Methodology Formulas），我将为您对第三阶段的每一个损失函数进行极具深度的数学展开，并配以明确的物理意义解释。

在进行具体公式推导前，我们需要统一定义一个前提：
由于输入是特征图（Feature Maps），形状为 `(Batch, Channels, H, W)`，在计算对比损失时，通常需要通过**全局平均池化 (GAP)** 或 **空间展平 (Spatial Flattening)** 将其转换为向量 $z \in \mathbb{R}^d$，以便计算余弦相似度（Cosine Similarity）。我们将相似度函数定义为：
$$\text{sim}(u, v) = \frac{u^T v}{\|u\| \|v\|}$$

以下是详细的公式级实施方案：

---

#### 1. 结构子空间 Symile 联合对比损失 ($\mathcal{L}_{symile\_S}$)

**物理目标：** 强迫网络利用所有可用的结构线索（无论显式还是隐式），联合重构出完美的小波高频真值。

**输入集合：**
定义结构空间的特征集合为 $X_{struct} = \{z_1, z_2, z_3, z_4\}$，其中：
* $z_1 = S_{pstm}$ （PSTM的显式结构）
* $z_2 = S_{horizon}$ （层位的绝对边界）
* $z_3 = S_{rms}$ （RMS的隐式速度阶跃）
* $z_4 = Anchor_{struct}$ （目标深度速度的小波高频分量，**物理真值**）

**上下文聚合 (Context Aggregation)：**
Symile 的核心是“留一法 (Leave-One-Out)”。对于集合中的每一个元素 $z_k$，我们需要聚合剩余的 3 个元素来形成上下文向量 $c_{S, k}$。我们定义一个聚合神经网络 $\mathcal{A}_S$（通常是一个浅层 MLP）：
$$c_{S, k} = \mathcal{A}_S \left( \frac{1}{3} \sum_{j \neq k} z_j \right)$$
*(物理意义：例如当 $z_k$ 是 $Anchor_{struct}$ 时，$c_{S, k}$ 就是网络尝试用 PSTM、层位和 RMS 联合拼凑出来的预测结构图。)*

**联合对比公式：**
利用 InfoNCE 范式，强迫 $z_k$ 与它的联合上下文 $c_{S, k}$ 在 Batch 内对齐：
$$\mathcal{L}_{symile\_S} = - \frac{1}{4} \sum_{k=1}^{4} \frac{1}{B} \sum_{i=1}^{B} \log \frac{\exp(\text{sim}(z_{k}^{(i)}, c_{S, k}^{(i)}) / \tau_S)}{\sum_{j=1}^{B} \exp(\text{sim}(z_{k}^{(i)}, c_{S, k}^{(j)}) / \tau_S)}$$
其中，$B$ 是 Batch Size，$\tau_S$ 是结构空间的温度超参数（通常设为 0.07 或 0.1）。

---

#### 2. 数值子空间 Symile 联合对比损失 ($\mathcal{L}_{symile\_N}$)

**物理目标：** 强迫网络结合平滑的背景与稀疏的硬约束，联合逼近真实的绝对速度分布。

**输入集合：**
定义数值空间的特征集合为 $X_{num} = \{v_1, v_2, v_3, v_4\}$，其中：
* $v_1 = N_{rms}$ （RMS的平滑背景速度）
* $v_2 = N_{well}$ （测井的绝对速度硬约束）
* $v_3 = N_{pstm}$ （PSTM的隐式运动学特征/振幅信息）
* $v_4 = Anchor_{num}$ （目标深度速度的小波低频近似分量，**物理真值**）

**上下文聚合 (Context Aggregation)：**
同样定义数值空间的聚合网络 $\mathcal{A}_N$：
$$c_{N, k} = \mathcal{A}_N \left( \frac{1}{3} \sum_{j \neq k} v_j \right)$$

**联合对比公式：**
$$\mathcal{L}_{symile\_N} = - \frac{1}{4} \sum_{k=1}^{4} \frac{1}{B} \sum_{i=1}^{B} \log \frac{\exp(\text{sim}(v_{k}^{(i)}, c_{N, k}^{(i)}) / \tau_N)}{\sum_{j=1}^{B} \exp(\text{sim}(v_{k}^{(i)}, c_{N, k}^{(j)}) / \tau_N)}$$
*(物理意义：这一项使得测井的高置信度单点值能够像“墨水”一样，顺着 RMS 和 PSTM 提供的联合上下文网络，晕染扩散到整个低频速度场真值上。)*

---

#### 3. 特异性正交惩罚 (QUEST Orthogonality Constraint) ($\mathcal{L}_{ortho}$)

**物理目标：** 结构头（$S$）和数值头（$N$）在 Symile 的驱使下会拼命寻找“共性”。如果不加限制，特异性头（$U$）也会去学习这些共性以走捷径（Shortcut）。正交约束强制 $U$ 必须保留不属于 $S$ 和 $N$ 的独立物理信息（例如测井的观测噪声、PSTM的特定反射振幅异常）。

**具体公式：**
对于模型输入中的每一个模态 $m \in \{pstm, horizon, rms, well\}$，我们强制其提炼出的特异性特征 $U_m$ 与其自身的共享特征正交（即余弦相似度为 0）。

使用**绝对余弦相似度**作为惩罚项（越趋近于 0 越好）：
$$\mathcal{L}_{ortho} = \sum_{m} \left( \lambda_{S} \cdot \left| \text{sim}(U_m, S_m) \right| + \lambda_{N} \cdot \left| \text{sim}(U_m, N_m) \right| \right)$$
*(注：如果某个模态没有被显式分配到结构或数值空间——比如假设我们在设计时认定 Horizon 绝对不包含数值特征，那么就不计算那项惩罚。但根据您的假设，所有模态都具备双重属性，所以应该对 $S_m$ 和 $N_m$ 都施加惩罚。)*

---

#### 4. 总体预训练损失函数 ($\mathcal{L}_{Total\_Pretrain}$)

在纯化子空间的预训练阶段，我们将上述三个损失组合，通过一组权重超参数（$\alpha, \beta, \gamma$）来平衡训练的侧重点。

$$\mathcal{L}_{Total\_Pretrain} = \alpha \cdot \mathcal{L}_{symile\_S} + \beta \cdot \mathcal{L}_{symile\_N} + \gamma \cdot \mathcal{L}_{ortho}$$

**💡 代码落地与论文写作的重要提示：**
1. **权重的设置经验：** 通常 $\alpha$ 和 $\beta$ 可以同等对待（设为 $1.0$）。正交惩罚 $\mathcal{L}_{ortho}$ 是一个强正则化项，过大可能导致网络破坏特异性特征的提取，建议初始 $\gamma$ 设为 $0.1$ 或 $0.05$。
2. **正反向对比计算（Symmetric Loss）：** 在实际编写 `Symile Loss` 时，建议像 CLIP 那样使用对称损失：既要用 $(z_k)$ 去匹配 $(c_{S, k})$，也要反过来用上下文 $(c_{S, k})$ 去匹配 $(z_k)$。即公式中的相似度矩阵的行和列分别求交叉熵并平均，这能使训练更稳定。
3. **空间特征图的处理技巧：** 在送入以上公式计算前，不要直接在 $70\times70$ 的像素级做 InfoNCE（计算量爆炸）。最好的做法是：**对特征图应用 Global Average Pooling (GAP) 得到 1D 向量来计算 Contrastive Loss**。这保证了网络在“宏观语义”上实现了解耦。当您把这套参数带入后续的 Diffusion 时，不用 GAP，直接拼接 $70\times70$ 的特征图，网络依然能完美识别出高低频的空间位置！

---

### 第四阶段：特征注入与流扩散网络搭建 (Diffusion U-Net Integration)
**目标：利用已被“物理升华”的解耦特征指导 Diffusion 生成速度模型。**

1. **特征拼接聚合：**
   * 获取预训练网络输出的基础特征 $F$、结构特征图 $S$ 和数值特征图 $N$。
   * 在通道维度进行级联：$Condition\_Token = \text{Concat}(F_{base}, S, N)$。
2. **Cross-Attention 注入：**
   * 将拼接好的 $Condition\_Token$ 展平为序列。
   * 送入 Flow Diffusion U-Net（主干网络）的各个 Cross-Attention 层中。
   * *物理意义：* U-Net 既能看到兜底的全量信息 ($F$)，又能直接拿到高频结构图 ($S$) 和低频背景图 ($N$) 作为显式的生成参考。



**给您的实操建议：**
先在您的小型子数据集（例如 Marmousi 的几个 Patch）上完整跑通 **第一阶段** 到 **第三阶段**。您可以直接可视化输出的 $S_{map}$ 和 $N_{map}$ —— 如果您的网络设计正确，您会非常直观地看到 $S_{map}$ 呈现出清晰的地层边缘线，而 $N_{map}$ 呈现出平滑的色块。确认这一步成功后，再接入庞大且吃显存的 Diffusion 模型！

#### Symile 消融实验

当前代码支持两种 Symile 策略，均保留结构空间、数值空间两套损失。推荐主实验使用官方路线，并叠加增强项：

```yaml
contrastive_learning:
  loss:
    symile_mode: 'official_mip_shuffle'
    include_all_modalities_in_symile: true
    gamma: 0.05
    anchor_alignment_weight: 1.0
    sn_ortho_weight: 0.05
    modality_adv_weight: 0.5
    modality_adv_grl_lambda: 2.0
```

这一路线表示：
* 主对比损失使用官方 O(B) shuffle Symile；
* 默认将所有模态的 `S/N` 头都纳入 Symile 和 anchor alignment；
* 强化 anchor alignment，使 `S` 更贴近高频结构锚点、`N` 更贴近低频数值锚点；
* 适当放松 `S-N` 正交和 `U-(S,N)` QUEST 正交，避免正交项已经很低时继续压制有效特征；
* 加强 `S/N` 头上的 GRL 模态对抗，使其更难保留 “PSTM / Horizon / RMS / Well” 的身份信息。

当前 adv-strong 重训练使用 `val/selection_loss` 进行 early stopping 和 checkpoint 选择：

$$
\mathcal{L}_{selection}
=
\alpha \mathcal{L}_{symile\_S}
+ \beta \mathcal{L}_{symile\_N}
+ \gamma \mathcal{L}_{QUEST}
+ \lambda_A \mathcal{L}_{anchor}
+ \lambda_{SN} \mathcal{L}_{SN}
$$

`selection_loss` 不包含 `modality_adv`。原因是 GRL 对抗项在总训练损失中仍然参与反向传播，但若直接用包含该项的 `val/loss` 选择 checkpoint，模态分类器过强、特征仍然保留模态身份时，反而可能因为分类交叉熵很低而被误选为“更好”的 checkpoint。训练后需要同时检查 `val/modality_adv_structure_accuracy` 和 `val/modality_adv_numerical_accuracy`，理想情况是它们明显低于旧实验的 `1.0`，并向四分类随机水平 `0.25` 靠近。

```yaml
contrastive_learning:
  loss:
    symile_mode: 'context_mlp'
```

`context_mlp` 仍然保留作为消融版本：对其他模态做 leave-one-out 平均聚合，再经过 MLP 得到上下文，用 batch 内 InfoNCE 对齐。

`official_mip_shuffle` 是贴近官方 Symile 的版本：GAP 和 projector 后，使用多线性内积 MIP：

$$
\text{MIP}(x,y,z,a)=\sum_d x_d y_d z_d a_d
$$

负样本采用官方 O(B) shuffle 策略：每个模态轮流作为 anchor，其余模态在 batch 维随机打乱后逐元素相乘，形成跨样本错配的负组合；正样本仍放在 logits 对角线上。
