# Step 2M supplementary-code attachment

The accompanying reviewer-facing source code ZIP is generated by `reproducibility/prepare_step2m_supplement.py` from the final Step 2M commit. It is supplied as an artifact for submission preparation, **not** evidence that any file has been uploaded to MDPI.

Included: project-owned model/data/training/evaluation/diagnostics Python, release configs, tests, dependency pins, and documentation/entrypoints (prepare, train, evaluate, smoke, validate). The ZIP includes checksums and exact Git snapshot information.

Excluded: OpenFWI/SeisMIC-Init data arrays, LMDB stores, checkpoints, experiment logs, raw outputs, temporary caches, machine credentials and third-party baseline implementations whose redistribution rights have not been established. The public repository does not yet declare a reusable project license. Accordingly, the paper code package is **not a fully self-contained reproduction of all external baseline results**. A publication-specific public release requires a separate authorship/license and data/checkpoint release decision.

The public SeisMIC-Init Hugging Face dataset is a related resource, not a verified complete copy of the study-specific 336,000-record OpenFWI eight-subset materialization.

See the ZIP's `SUPPLEMENTARY_README.md` and `SOURCE_SHA256SUMS.txt` for exact contents.
