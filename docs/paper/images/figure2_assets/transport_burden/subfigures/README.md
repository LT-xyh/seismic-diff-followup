# Residual Transport 3-Stage Subfigures

These are the three standalone image tiles used by residual_transport_3stage.

- stage1_noise_xi.png: source noise field xi ~ N(0,I).
- stage2_interpolated_Rt.png: intermediate residual-space interpolation R_t.
- stage3_target_residual_Rhat.png: structured residual target/proxy for hat R.

The `_900.png` files are normalized 900 x 900 versions for manual figure
composition.
